### Basic Chatbot

## Overview
The Basic Chatbot is a simple rule-based chatbot developed using Python. It interacts with users by responding to predefined questions and demonstrates the fundamentals of conversational programming.

## Features
- Interactive text-based conversation
- Predefined responses to common questions
- User-friendly interface
- Simple and easy-to-understand logic
- Demonstrates basic chatbot functionality

## Technologies Used
* Python
* Visual Studio Code (VS Code)
                                                                   
## Learning Outcomes
- Python Programming Fundamentals
- Conditional Statements (if-elif-else)
- Functions
- String Manipulation
- User Input and Output Handling
